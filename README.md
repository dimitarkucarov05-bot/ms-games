# Арена

Работно копие на системата за VR арената, подредено на 12.11.2026.
Оригиналът от архива „Арена за Мартин.zip" стои непипнат в `_original/`.

## Какво има тук

| Папка | Какво е | Състояние |
|---|---|---|
| `lobby/` | Пултът на оператора: каски, зала, калибровка, игри, мач. Node.js, порт 47801. | Работи. Нов интерфейс. |
| `labcoin-app/` | LabCoin Арена за рождените дни (куиз, отбори, точки, класиране). Порт 4780. | Работи, 11/11 теста. Не е пипано, освен `npm test`. |
| `public-leaderboard/` | Cloudflare Worker за публичния лидерборд с QR. | Само код. Не е пускан оттук и не бива без Митко. |
| `docs/` | Документите от архива + `КОНЦЕПЦИЯ.md` (нашата игра и техническият план). | |
| `_original/` | Архивът, както дойде. | Не се пипа. |

## Пускане

```bash
cd lobby
npm install     # само първия път
npm start       # http://localhost:47801
```

Проба без каски (в отделен прозорец):

```bash
cd lobby
npm run sim     # 6 измислени каски
```

LabCoin приложението:

```bash
cd labcoin-app
npm install
npm test
npm start       # http://localhost:4780
```

## Какво липсва, за да влезе истинска каска

В архива **няма игра**. Старата игра е на Unreal, правена е за PICO каски и нарочно не е сложена
(платени модели). Нашите каски са Meta Quest 2, за които клиент още няма.
Пултът е готов да ги приеме, щом има игра, която говори протокола от `lobby/PROTOCOL.md`.
Планът за тази игра е в `docs/КОНЦЕПЦИЯ.md`.

## Какво е сменено спрямо архива

Пултът (`lobby/`):

- Интерфейсът е написан наново: `public/index.html`, `console.css`, `console.js`.
  Тъмен неутрален, един сигнален цвят, шрифт Sofia Sans (локално, работи без интернет).
- Екранът се обновява на място. Преди целият списък се прерисуваше при всяко съобщение от каска
  (до няколко пъти в секунда), което губеше кликове и мигаше.
- Няма изскачащи прозорци на браузъра (`confirm`, `prompt`). Опасните бутони искат второ натискане,
  преименуването става на място с двоен клик.
- Калибровката е на страницата, не в модален прозорец.
- Махнати от екрана: всичко само за PICO (LBE карти, LSpace, „Сподели LBE зона", рестарт на каска)
  и раздел „Кредити" (списъкът е за материалите на старата игра; пази се в `lobby/docs-old/`).
- Камерите от Unreal се показват само ако играта на компютъра наистина върви.
- `server.js` вече е по-новата версия (бившият `server.js.next`), която праща края на рунд и мач
  към LabCoin приложението.
- UDP „тук съм" към мрежата е **изключено по подразбиране**. Трябва само на старата Unreal игра
  и може да дръпне каски от друго лоби в същата мрежа. Включва се с `BEACON=1 npm start`.
- Изтрити мъртви файлове: `lobby.js.bak_arena13b`, старият `app.js` и `style.css`,
  48 стари кадъра от камери (6,6 MB).

Още стои (не пречи, но е излишно за Quest): кодът за PICO LBE и гласуването за карта в `server.js`.
Маха се, когато сървърът се преподрежда за новата игра.

## Правила, наследени от архива

Те са на Митко и важат за живата арена на VR Varna, не за това копие:

- сайтът и панелът на VR Varna не се пипат;
- в лобито на живата арена нищо не се рестартира без него;
- ключове и пароли не се пращат в чат и не се качват в git.

Това копие не се свързва с нищо от живата система.
