# MacBook: цялата система от GitHub

Работи на Mac така, както е (Node, без build). Двоен клик на **`start-mac.command`** в корена на репото: сам прави `git pull`, пита за Node 24, ако липсва,
прави връзките към активите и пуска **пълния** сървър (не пробния): конзола, игри, ТВ, страница за сканиране, HTTPS и радио-маякът, по който каските намират компютъра.

| Какво | Адрес |
|---|---|
| Конзола (на Mac-а) | http://localhost:47801 |
| Служебен телефон, **камера работи** | https://&lt;IP на Mac-а&gt;:47843/scan/ (приеми предупреждението за сертификата веднъж) |
| Служебен телефон, код на ръка | http://&lt;IP на Mac-а&gt;:47801/scan/ |
| Каски (Quest) | https://&lt;IP на Mac-а&gt;:47843/play/ (адресът излиза и в терминала) |

- **Защо пълен, а не пробен сървър:** `tools/dev-server.mjs` нарочно изключва HTTPS, радио-маяка и пазача на каските. Без HTTPS нито камерата на телефона,
  нито каските във VR работят.
- **Mac и мрежа:** телефонът и каските да са в същата Wi-Fi мрежа като Mac-а. macOS може да поиска разрешение за входящи връзки на Node: „Allow“.
- **Сън:** стартерът държи Mac-а буден (`caffeinate`), докато върви.
- **USB инсталатор на каските (adb):** изключен (`NO_KEEPER=1`); иска Android platform-tools за macOS. Играта по Wi-Fi не го иска.
- **Данни:** `lobby-stage/data-mac/` (извън git): зона, калибровки, рекорди, `labcoin.json` (ключът на LabCoin), дневник на HEX.
- **LabCoin:** `data-mac/labcoin.json` = `{"baseUrl":"https://app.labcoin.bg","key":"…","venue":"…","mode":"live","grantPin":"…"}`; проверка: `curl -X POST localhost:47801/api/labcoin/check`.
