    How it works
    1. Mark the four corners of the arena on the floor and number them 1 to 4 in order. Corner 2 is along the long wall from corner 1.
    2. Pick a headset from the list and put it on.
    3. Touch the right controller to each corner and pull the trigger. Four times, in the same order.
    4. Check the size and save. Every headset goes through the same corners in the same order.
