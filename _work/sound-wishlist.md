# Sound wish list for The Motel (real recordings and professional library sounds only)

Numbers are the wanted count of VARIANTS (different takes), so repeated events do not sound like a machine.
Final files: mono, 44.1 kHz, OGG Vorbis (about quality 5), silence trimmed, short fades, peak about -1 dBFS,
loudness matched inside each family. Loops must loop without a click. Folder: `public/play/assets/sfx/<family>/`.
File names: `<event>_<n>.ogg`, lower case, e.g. `pistol_shot_1.ogg`.

## weapons (family `weapon`)
- Shots, single, close perspective, with a short tail: pistol 4, smg 4, revolver 3, shotgun 3, carbine (5.56 assault
  rifle) 4, rifle (7.62) 4, hunting rifle (bolt action, big) 3, light machine gun 4.
- dry fire click 2; magazine out 2; magazine in 2; slide or bolt rack 3; shotgun shell insert 3; shotgun pump 2;
  revolver cylinder open, shells, close 1 each; belt or cover clatter for the machine gun 2.
- brass casing on asphalt 4; shotgun shell on asphalt 2.
- bullet hits: flesh 5, wood 3, metal 3, concrete or dirt 3; bullet whiz-by 4.
- melee: light swing whoosh 3, heavy swing whoosh 3, axe into flesh 4, machete slash 4, blunt hit 3.
- chainsaw: pull start 1, idle loop 1, full throttle loop 1, cutting flesh loop 1, stop 1.
- handling: weapon picked up (metal rattle) 3, gun dropped on asphalt 3, wooden handle tool dropped 2,
  hammer on wood or nail 5, plank put in place 3, flashlight click 2.
- explosion near 3, explosion far 2, debris falling 2.
